# Refresh an OSF entity

Use `osf_refresh()` to update one or more entities in an
[`osf_tbl()`](https://docs.ropensci.org/osfr/reference/osf_tbl.md) with
the latest information from OSF.

## Usage

``` r
osf_refresh(x)
```

## Arguments

- x:

  an [`osf_tbl`](https://docs.ropensci.org/osfr/reference/osf_tbl.md).
